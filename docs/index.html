Message

Your voice messages stay yours.

Audio stays in memory. It's decoded, transcribed and dropped. Nothing is written to disk.

No transcripts kept. The bot replies and forgets. It only remembers each chat's settings.

No cloud services. The models run on your own CPU. You can add a cloud API, but you don't have to.

Only people you allow. Anyone else is told their sender ID and nothing more.

The messenger itself still delivers the message, like any other chat.

Use the messenger you already have.

Telegram Create a bot with @BotFather and paste the token. No public URL needed.

Signal Give the bot its own number, or link it to yours and forward to Note to Self.

WhatsApp Through WAHA. Use a spare number: WhatsApp doesn't allow unofficial clients.

Switch the engine in any chat.

NVIDIA Parakeet v325, detected automatically3.0 s14.8 s

Measured on an Intel i5-12400 without a GPU. Parakeet is the default; Canary is more accurate on difficult audio. Any OpenAI-compatible API works too.

Send these in any chat with the bot.

/engines
List the engines and show the one this chat uses
/engine canary
Switch this chat to another engine
/lang de
Set the spoken language for Canary (/lang auto resets it)
/details on
Show engine and timing under each transcript

Running in a few minutes.

git clone https://github.com/then4p/tldl.git && cd tldl
cp config.example.yaml config.yaml
cp .env.example .env
docker compose up -d

Needs Docker. Fill in your bot token and allowed senders, then start it. It uses about 0.8 GB of RAM while a model is loaded and about 0.1 GB when idle.
